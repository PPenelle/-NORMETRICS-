# -NORMETRICS-
Normetrics™ — A unified API for norm-based linear models

Normetrics is an API for defining and running linear models using a unified formulation based on linear operators and norm-based objectives.

It provides a consistent way to express commonly used techniques such as:

- Ordinary least squares (OLS)
- Generalized least squares (GLS)
- Fixed-effects and difference models
- Instrumental variables (IV / 2SLS)
- Moment-based estimation (GMM-style formulations)

Normetrics supports multiple loss geometries:

- L2 (mean-based estimation)
- L1 (robust / median-based estimation)
- L∞ (minimax / worst-case estimation)

and allows these to be combined with regularization techniques such as L1, L2, and elastic net.
